# Cardio · 把每次相遇，沉淀为可决策的研判

> **输入一家目标公司或一个机会，Cardio 用五段管线给出结构化研判——提取、调研、综合、策略、批判性审视，一条链路走完。名片与客户档案是研判的入口，商枢是伴随的 AI 咨询助手。**

Cardio 是一个面向 BD（商务拓展）/ 销售场景的分析服务：把散落在各处的企业信息，压缩成一份可决策的结构化研判。

## 它解决什么问题

BD 跟进的每一步都卡在同样三件事上：**资料散**（财报、新闻、招聘、官网各在一处）、**研判慢**（读完全部材料半天过去）、**结论软**（"感觉靠谱"支撑不了上会）。

Cardio 把这三步变成一条五段管线：

```
extraction → research → synthesis → strategy → critique
  提取关键信息   深度调研    综合研判     策略建议    批判性审视
```

- **提取**：从目标企业资料中抽取关键信息，形成结构化事实底稿
- **调研**：围绕底稿做深度调研，补充交叉信息
- **综合**：把事实与调研结果综合成一份研判
- **策略**：给出可执行的跟进策略建议
- **批判**：对前面所有结论做一次批判性审视——**专门挑自己毛病的那一段**

你拿到的不只是答案，还有答案被审视过的过程。

## 三条产品主线

Cardio 由一条核心主线与两条伴随副线组成，彼此衔接但职责清晰。

### ① 五段研判（核心）

所有价值的落点。输入目标企业或机会描述，提交后即进入持久化编排的五段管线；每段独立产出、可分别回看，最后由 critique 段给出"最可能错在哪"。

- 任务跑在**持久化执行引擎**上：自动重试、断点恢复，中途离开或刷新页面，回来结果还在。
- 历史研判可在「历史研判」中完整回看每一次的五段输出。

### ② 数字商册与通讯录（副线：研判的输入入口 / 轻 CRM）

名片、会议资料、官网截图，是研判最常见的原材料。Cardio 让你把这些"相遇"沉淀为客户档案：

- 上传名片或截图 → 视觉提取关键字段 → 落库为联系人档案；
- 任意联系人可**一键发起五段研判**，把零散的客户信息直接变成结构化决策。

它是研判的"客户输入入口"，也是你自己的轻量人脉库。

### ③ 商枢·AI 咨询助手（伴随副功能）

独立于研判主流程的通用商务咨询助手（基于你自备的模型，流式对话）。它不介入研判的数据流，定位是"随时问、随手记"的伴随工具——在你做研判前后，帮你推敲话术、拆解问题、整理思路。

> 三条线共享同一套账号、BYOK 模型与配额；研判是主轴，商册与商枢围绕它服务。

## 使用方式

1. 打开 **[cardio.sy-realm.ltd](https://cardio.sy-realm.ltd)**，注册并登录（邮箱验证闭环）
2. 在模型配置中填入你自己的 API Key（**BYOK**——模型成本自控，平台不代垫）
3. 新建一次研判：
   - **直接输入**目标企业或机会描述，提交五段管线；或
   - 先在「商册通讯录」上传名片/截图沉淀为客户档案，再一键发起研判
4. 每段耗时分钟级，任务持久化执行——中途离开、刷新页面，回来结果还在
5. 在「历史研判」中回看每一次分析的完整五段输出；需要时随时切到「商枢」推敲思路

> 免费额度：每用户每日 3 次研判；额度用尽时自动使用本地兜底模式，不中断使用。

### 本地开发（可选）

```bash
# 后端（FastAPI + Temporal worker）
python -m venv venv && source venv/bin/activate
pip install -e .
cp .env.example .env   # 编辑 .env 填入 LLM API key

# 前端（cardio-web/，React + Vite）
cd cardio-web && pnpm install && pnpm dev
```

## 技术与特色

| 层 | 选型 |
|---|---|
| 前端 | React 19 · Vite 8 · Tailwind CSS 4 · React Router 7 |
| 后端 | FastAPI · Pydantic v2 · SQLite |
| 任务编排 | 持久化工作流引擎（五段顺序编排、自动重试、状态可查询） |
| LLM 接入 | 统一网关 + 用户级配额；hermes_core 共享库 |

**工程特色**：

- **前端零依赖路由框架之外的状态管理**——单页工具，views/ 目录自管视图，不引不需要的能力
- **LLM 调用统一走网关**：超时、重试、配额一处收敛，产品代码不各自造轮子
- **构建链保鲜**：Vite 8（Rolldown 内核）+ plugin-react 6，冷启动与 HMR 为当前代事实标准
